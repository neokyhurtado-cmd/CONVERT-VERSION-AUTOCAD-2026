DATOS CLAROS, DECISIONES CORRECTAS

Lo importante
de verdad.

La herramienta detecta formatos y ayuda a convertirlos, pero no promete reparar dibujos dañados ni garantizar equivalencia técnica del 100 %.

¿Puedo convertir directamente en la web? +

No. En esta página puedes identificar el formato DWG sin subirlo. Para crear otra versión, necesitas el conversor local de Windows con AutoCAD instalado y licenciado.

¿Y si no tengo AutoCAD? +

Autodesk ofrece DWG TrueView, una herramienta gratuita que incluye conversión de versiones por lotes. No necesitas nuestro programa para utilizarla.

¿Sirve para AutoCAD 2027 y 2018? +

Sí, ambos usan el formato DWG 2018 (AC1032). Que un archivo sea de 2027 no significa necesariamente que haya que convertirlo para abrirlo en AutoCAD 2018; también importa el contenido del dibujo.

¿Modifica mis archivos originales? +

El diagnóstico web no modifica archivos. El asistente local guarda copias con nombres nuevos y genera un informe. Aun así, haz una copia de seguridad antes de convertir planos importantes.

¿El plano convertido conserva todo? +

No podemos garantizar equivalencia 1:1. Bloques dinámicos, XREF, objetos proxy y estilos de productos verticales pueden cambiar al guardar en formatos antiguos. Revisa tu archivo antes de entregarlo profesionalmente.

¿Funciona en Mac? +

La identificación del formato funciona en navegadores modernos de Mac, Windows y móvil. El conversor descargable de esta versión está diseñado solo para Windows con AutoCAD de escritorio.
